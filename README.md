# Stompdesk

Pedalboard virtual para guitarra no Windows: efeitos embutidos e VST3, ASIO/WASAPI, looper, metrônomo que segue a música, afinador, atalhos de teclado e MIDI, e um player do YouTube que tira voz, guitarra e outros instrumentos para você tocar junto.

## Download

Pegue o zip da [última versão](https://github.com/CassioNathan/stompdesk-releases/releases/latest), extraia e abra `Stompdesk\Stompdesk.exe`.

- Windows 10/11, 64 bits.
- Na primeira vez que for separar uma música, o PyTorch é baixado (uma vez só).
- O app avisa quando sair versão nova e se atualiza sozinho.

Este repositório só guarda as versões publicadas.
